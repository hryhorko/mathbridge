\# Contributing to MathBridge



Thank you for your interest in MathBridge EdTech.



MathBridge is an open-source educational project focused on integrating

ATutor LMS, JupyterHub and SageMath into a unified learning ecosystem.



\## How to contribute



Contributions are welcome through:



\- bug reports;

\- documentation improvements;

\- feature requests;

\- code enhancements;

\- educational examples.



\## Development workflow



1\. Fork the repository (or create a feature branch).

2\. Create a separate branch for each feature or bug fix.

3\. Commit small, meaningful changes.

4\. Open a Pull Request with a clear description.



\## Coding guidelines



\- Follow PEP 8 for Python code.

\- Use meaningful commit messages.

\- Keep documentation up to date.

\- Never commit passwords, secret keys or tokens.



\## Reporting issues



Please use GitHub Issues and provide:



\- operating system;

\- software versions;

\- steps to reproduce;

\- expected behaviour;

\- actual behaviour.



Thank you for helping improve MathBridge.
